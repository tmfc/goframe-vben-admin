# Specification: 租户管理功能实现 (Tenant Management)

## 1. 概述 (Overview)
在系统管理模块中添加“租户管理”功能，支持全栈实现（后端接口 + 前端 Naive UI 页面）。该功能旨在让管理员能够维护系统中的租户信息，包括基本资料、有效期及状态控制。

## 2. 功能需求 (Functional Requirements)

### 2.1 后端实现 (Backend)
- **CRUD 接口**: 实现租户实体的增删改查 API。
- **状态切换**: 支持启用/禁用租户。
- **软删除**: 租户数据支持软删除及恢复。
- **数据结构**: 租户实体包含以下字段：
  - 租户名称 (Tenant Name)
  - 租户代码/唯一标识 (Tenant Code)
  - 联系人及联系电话
  - 有效期（开始日期 & 结束日期）
  - 关联套餐/版本 (Package/Version)
  - 租户域名/子域名 (Domain/Subdomain)

### 2.2 前端实现 (Frontend - Naive App)
- **页面布局**: 采用经典的“表格 + 弹窗 (Modal) 表单”模式。
- **功能点**:
  - 租户列表展示（支持分页、搜索）。
  - 创建租户（弹窗表单）。
  - 编辑租户信息（弹窗表单）。
  - 租户状态切换开关。
  - 删除租户（带确认提醒）。
  - 查看租户详情。

## 3. 非功能需求 (Non-Functional Requirements)
- **一致性**: UI 风格需与 Vben Admin Naive UI 版本保持一致。
- **验证**: 前后端均需对租户代码（唯一性）、有效期等关键字段进行校验。
- **现有框架**: 利用现有的租户隔离框架，确保管理操作符合系统架构。

## 4. 验收标准 (Acceptance Criteria)
- [ ] 后端租户管理 API 能够正常响应，并正确处理数据库操作。
- [ ] 前端页面能正确渲染租户列表，并实现与后端的联调。
- [ ] 租户的创建、更新、禁用、删除功能均通过测试。
- [ ] 代码覆盖率符合项目要求（>80%）。

## 5. 超出范围 (Out of Scope)
- 租户隔离逻辑的底层框架开发（已存在）。
- 具体的租户内业务数据迁移工具。
